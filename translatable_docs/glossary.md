## 七、控制码（不翻译，原样保留）

`<NAME/>`/`<SURNAME/>`（主角名/姓，软码可挪位）、`<pause:N/>`、`<cNN/>`（未命名控制码，如 `<c12/>`，原样保留）、`\n`（换行）。详见单独的「控制符列表」。**铁律：硬码数量/参数/`\n` 个数必须和原文完全一致。**

## 九、翻译原则

1. **意译 > 直译**：语尾词转成对应中文口气，不死译
2. **控制码 / `\n` 位置不动**：数量、参数、位置和原文完全一致
3. **不要超长**：apply 会校验长度，超原槽就跳过，中文尽量精炼
4. **新名词先登记本表**，避免叫法不一

## 十、批量统一名词（重要：别在平台一条条改）

一个名词出现几百次，**不要在协作平台逐条搜改**——用 `name_fix.py`：

```python
# name_fix.py 的 FIXES：错写法 → 对写法
FIXES = {
    '麻耶': '舞耶', '雪乃': '雪野', '达也': '龙也',
    '米歇尔': '米切', '银狐': '银子',
}
# 跑一遍 → all_translatable.json + 所有 out/*_zh.json 里全部统一
```

**加一行 + 跑一次 = 几百处一次性统一。** 平台只用来改句子级翻译，名词统一交给这个脚本。
